# Real-Time Chat Application

A full-stack real-time chat app with user presence, typing indicators, and message history — built with Node.js, Express, and Socket.io.

## Features
- 💬 Instant messaging with WebSockets
- 👥 Live online user list
- ⌨️ Typing indicators
- 📜 Message history for new users (last 100 messages)
- 🚪 Join/leave system notifications
- 🛡️ XSS protection & unique usernames

## Tech Stack
- **Backend:** Node.js, Express, Socket.io
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Real-time:** WebSockets (Socket.io)
